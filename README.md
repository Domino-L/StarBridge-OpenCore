# 星海舰桥 StarBridge

面向《星际公民》玩家社区的 Windows 舰队协作工具。当前为公开测试版。

星海舰桥把舰队、小队、临时组队房间、好友通讯、个人资料、机库整理和游戏浮层集中在一个桌面应用中。它的两项核心能力是：

1. **只读监听用户主动选择的 `Game.log`，把稀疏的日志信号整理为可读的玩家、飞船、地点和游戏状态；**
2. **使用独立的 Windows 透明窗口绘制游戏浮层，在不修改游戏画面的情况下展示协作信息。**

## 核心功能一：`Game.log` 实时监听

### 它是怎样工作的

星海舰桥不会连接游戏进程读取内存，也不会从游戏画面中识别文字。用户需要在“账号与识别”中自动扫描或手动选择：

```text
StarCitizen\LIVE\Game.log
```

受支持的处理链路如下：

```text
用户选择 Game.log
  → 校验文件名、存在性和可读性
  → 启动时只回看日志尾部，恢复近期状态
  → 约每 100ms 从上次位置继续读取新增行
  → 把匹配到的行归一化为内部事件
  → 用证据权重、优先级和时间衰减推断当前状态
  → 更新应用界面和游戏浮层
  → 登录后仅按用户的同步、隐私和事件共享设置发布允许共享的状态
```

具体实现：

| 阶段 | 实现方式 |
| --- | --- |
| 路径校验 | 只接受存在且可读的 `Game.log`。游戏仍在写入时，应用使用共享读取方式打开文件。 |
| 启动恢复 | 默认只读取日志末尾最多约 2 MB、1500 行，用于恢复近期身份、服务器、飞船和地点证据，不会在每次启动时扫描整份大文件。 |
| 实时追踪 | 监听器保存上次读取位置，约每 100ms 检查一次文件长度，只处理之后追加的完整日志行；日志被截断或轮换时会重新定位。 |
| 事件解析 | 编译后的规则把原始文本归一化为身份、游戏进程、服务器分线、飞船频道或控制信号、地点证据、导航目标、量子事件等内部事件。 |
| 状态推断 | 不会因为任意一行日志就无条件覆盖状态。强证据优先于弱证据，部分状态会随时间降低可信度；导航目标本身不会直接被当作已经抵达。 |
| 展示与同步 | 推断结果首先用于本地界面和浮层。联网状态、飞船、地点和事件是否对外同步，由账号状态与用户设置共同决定。 |

完整的公开算法、事件来源、分数规则和当前边界见 [Game.log 识别算法](docs/GAME_LOG_LISTENING_ALGORITHM.md)。

### 它能够辅助识别什么

- 当前日志中出现的本地游戏身份；
- 游戏是否运行、服务器分线及部分网络状态；
- 飞船频道、驾驶位或控制信号对应的当前飞船；
- 地点库存、明确区域、导航目标和量子航行产生的地点证据；
- 可被可靠样本支持的部分游戏事件；
- 供舰队、小队、房间和浮层使用的本地状态摘要。

“已识别”不代表来自 CIG 的权威实时接口。舰船、地点和事件中有一部分只能通过侧面信号推断。

### 日志识别的固有限制

- 游戏更新可能随时改变日志格式，使既有规则失效；
- 某些行为不会写入日志，或只在特定地点、飞船和流程中出现；
- 日志可能延迟、缺失、重复、乱序、被截断，或者直到稍后才出现关键证据；
- 导航目标不等于实际抵达，量子途中取消、任务点缺少区域确认等情况可能产生不确定结果；
- 飞船离座不一定代表离船，多人船内部活动也可能缺少明确的离船信号；
- 低、中、高可信度是应用的经验分级，不是官方数据，也不是统计学概率；
- 历史回放只用于恢复近期上下文，不能保证还原完整游戏过程；
- 任何舰船、地点、在线状态、死亡或其他事件判断都只应作为协作参考。

请勿仅凭星海舰桥的识别结果做出涉及游戏资产、账号安全、付费交易或其他重要事项的决定。

## 核心功能二：游戏浮层绘制

### 它是怎样工作的

游戏浮层不是注入到《星际公民》中的模组。星海舰桥在 Windows 桌面上创建独立的无边框透明窗口，再把应用已经拥有的状态绘制到该窗口。

| 环节 | 实现方式 |
| --- | --- |
| 窗口 | 独立、透明、置顶的 Windows 窗口；正常显示时不激活窗口并保持鼠标穿透，避免抢走游戏输入。 |
| 绘制 | 使用 DirectComposition 组织合成表面，使用 Direct2D 与 DirectWrite 绘制模块、文字、边框、泛光和转场。 |
| 状态 | 主应用生成显示快照，渲染线程只消费快照，不直接访问游戏进程。 |
| 布局 | 浮层编辑器与实际浮层共用布局和外观规则；模块的位置、尺寸、吸附、可见性和预设由用户保存。 |
| 控制 | 通过用户配置的全局热键开启或关闭浮层；可限制为游戏窗口位于前台时使用。 |

星海舰桥的浮层实现不会：

- 向游戏进程注入代码；
- Hook 游戏的渲染管线或游戏输入；
- 读取或修改游戏内存；
- 拦截或改写游戏网络通信；
- 修改《星际公民》客户端文件；
- 模拟操作、瞄准、移动或其他游戏行为。

这些是当前实现的技术边界，**不是 CIG、RSI 或反作弊系统作出的许可、安全认证或豁免**。

### 浮层的兼容性限制

- 独占全屏、Windows 合成策略、显示缩放、多显示器和 HDR 可能影响浮层位置或可见性；
- 显卡驱动、Windows 更新、录屏软件及其他浮层可能产生层级冲突、闪烁、黑屏或渲染失败；
- 全局热键可能与游戏、输入法或其他软件冲突，也可能被安全软件阻止；
- 高强度泛光、动效和大量模块会增加 GPU/CPU 开销，低配置设备可能出现掉帧或延迟；
- 游戏焦点识别可能出现短暂误判，浮层有可能显示在非游戏窗口上；
- 未来的游戏、反作弊或 Windows 安全策略可能使当前实现无法继续使用。

如果出现异常，请先关闭浮层；仍有问题时完全退出星海舰桥，并在重新使用前查看最新版本说明。

## 数据、联网与隐私边界

- `Game.log` 识别在本地开始执行，但应用不是纯离线软件；
- 登录、好友、舰队、小队、房间、消息、公开资料和允许共享的实时状态需要连接星海舰桥服务；
- 在线状态、飞船、地点、服务器分线及事件共享可以在设置中分别控制，隐身或离线模式会限制即时状态发布；
- 个人统计只有在用户明确同意后才开始记录；当前数据不应被视为官方生涯记录；
- 可选的地点代码贡献需要单独同意，提交内容用于改进代码与显示名称映射；
- 本地日志和诊断信息可能包含游戏 ID、服务器标识、地点代码、文件路径或其他个人信息；提交 Issue 前请先检查并删除不希望公开的内容；
- 应用不会要求或保存 RSI 账号密码，但内置网页功能及第三方页面仍受对应网站的账号与隐私规则约束。

请在“设置 → 同步与隐私”中确认共享范围。公开资料、舰队成员信息和聊天内容应按你愿意让对应接收者看到的程度填写。
