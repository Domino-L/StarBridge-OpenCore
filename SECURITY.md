# Security Policy

## Reporting a vulnerability

Please do not disclose a security vulnerability in a public issue.

Use GitHub private vulnerability reporting for the StarBridge Open Core
repository when it is available. If private reporting is unavailable, use the
contact method published on the official StarBridge website.

Include the affected component, expected impact, and a minimal reproduction.
Do not attach personal `Game.log` files, access tokens, account data, private
server addresses, signing material, or unrelated user information.

## Supported code

Security fixes target the current open-core branch. Older snapshots may not
receive separate fixes.
