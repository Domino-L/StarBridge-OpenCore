# StarBridge 自有交互包来源

本目录是 StarBridge 自有 Flutter 交互组件包，版本 0.1.0，按 Apache-2.0 随公开
仓库分发，完整许可见 [LICENSE](LICENSE)。它从项目的交互设计实验中导入，随后
增加客户端所需的键盘方向、读屏语义、焦点修复、宿主布局和减少动态支持。

本包仅依赖 Flutter SDK；测试依赖 Flutter Test 和 flutter_lints。依赖项仍受各自
上游许可约束，不因本包采用 Apache-2.0 而重新授权。本目录没有随附第三方素材、
字体、图像、业务场景、账号数据或构建产物。

客户端适配器拥有主题、设置、输入来源、业务命令和持久化。本包仅提供展示与
交互反馈，不拥有账号、服务器回执或业务状态。

公开源代码包含包级回归。自动化语义、布局与像素检查不等于真实读屏、Windows
DPI、性能或用户视觉验收。官方分发仍须走独立的精确来源审查与发布门禁，见
[官方分发说明](OFFICIAL_BINARY_DISTRIBUTION.md)。
