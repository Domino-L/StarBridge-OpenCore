# 星海舰桥 0.7.0.3 · 启动更新提醒

## 新增

- 进入应用后自动检查更新，发现新版本时显示专用更新窗口，无需先进入设置。
- 更新窗口突出新版本号，按标题、段落和列表展示更新公告，下载和重启操作保持在窗口底部。

## 优化

- 检查更新在后台静默进行；没有更新或暂时连接失败时不会弹窗打扰。
- 更新提醒等待当前操作和首次使用提示完成，不在后台抢焦点；同一次运行中不重复提醒同一个版本。
- 兼顾深浅色、小窗口和大字体显示。下载后仍需确认重启，未保存内容继续受原有保护。
- 对无法在应用内更新的安装，明确提示使用官网安装器升级，不再笼统显示“安装功能尚未开放”。

## 修复

- 修复部分安装中许可文件缺失导致测试版须知重复出现、点击“继续”仍无法进入的问题；保留已有确认记录。
- 改善启动时确认记录的读取：短暂读取失败会静默重试，避免将已有确认误判为首次使用。

## 使用说明

- 保留信息浮层，本版不提供菜单浮层。
- 当前为公开测试版，功能仍在完善；遇到问题可通过“帮助与支持”反馈。
