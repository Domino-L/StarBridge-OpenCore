# 星海舰桥 0.7.0.5 · 菜单浮层与游戏内工具

## 菜单浮层

- 游戏位于前台时，默认按 Alt+M 打开菜单，查看组织、好友、通讯和房间，也可从客户端的浮层页面打开。
- 多个窗口可同时打开、拖动和缩放，支持一键隐藏或恢复。未悬停 5 秒后，窗口会逐渐变淡；鼠标移回立即恢复，输入和拖动时不会触发。
- 修复点击前方窗口时，后方窗口意外浮到前面的问题。信息浮层保持在菜单下方，菜单中的信息浮层按钮直接控制开关。

## 浏览器、参考图与截图

- 浏览器支持多标签浏览与搜索，新标签页打开默认搜索引擎。与其他菜单窗口重叠时，未被遮挡的网页继续显示。
- 参考图支持双击切换纯图片模式，保留切换前的位置与大小；可拖动并调整不透明度，关闭菜单后可固定在游戏画面上。
- 截图可复制、保存到指定目录或另存为。请留意截图中的账号、聊天及其他私人信息，确认后再分享。

## 设置与体验

- 菜单浮层采用与信息浮层一致的“左侧分类、中间预览、右侧设置”布局。预览默认不展开工具窗口。
- 设置统一通过底部保存；关闭网页记忆并清除已记住的网址前会明确提示。网页记忆仅保存在本机，不保存浏览历史、不上传。
- 浮层页面顶部显示当前快捷键；信息浮层默认使用 Alt+O，保留已有的自定义快捷键。
- 改善设置说明、滚动条和长名称显示，修复部分设置首次读取与保存异常。

## 使用说明

- 本次更新不需要清空账号、个人资料或机库数据。
- 菜单操作继续遵守当前账号的权限和共享设置；不会因为打开菜单而增加查看权限。
- 当前仍为公开测试版，遇到问题可通过“帮助与支持”反馈。
