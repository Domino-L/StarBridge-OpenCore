# Synthetic UI regression fixtures

The four overlay-color-picker and overlay-import PNG files listed in
client-assets.json are generated by the Flutter widget tests
overlay_color_picker_test.dart and overlay_settings_test.dart. They render
StarBridge-authored controls and synthetic preset/sample data, not a user's
desktop, account, conversation, game capture, or commercial appearance artwork.
The authored test composition follows the repository source license. Bundled
Source font glyphs retain their SIL OFL licenses under assets/font-licenses.

These files are test-only comparison baselines, not runtime product media.
Their hashes are pinned in the asset inventory. Regeneration requires review;
do not update goldens just to suppress an unexpected visual regression.
