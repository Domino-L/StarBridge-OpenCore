# 星海舰桥 0.7.0.4 · 信息浮层与聊天体验更新

## 信息浮层

- 重新整理浮层设置，支持调整各模块布局、显示内容与透明度；准星颜色可通过颜色选择器设置。
- 支持保存、分享和导入浮层预设，导入前可查看布局与详细设置。导入不会覆盖当前预设或未保存的调整，自动切换默认关闭。
- 聊天可同时选择房间和组织等多个来源，每条消息标明来源；支持消息列表和弹幕显示，分享的预设等附件会提示前往客户端查看。
- 优化来源状态提示和后台恢复；切换账号、退出来源或失去权限后，及时清除不再有权查看的内容。

## 聊天与房间

- 改善组织聊天的新消息接收、未读提醒和进入聊天后的已读更新，统一未读提示外观。
- 发送消息后先显示本机气泡，并在气泡内呈现发送进度与失败状态。
- 优化房间后台刷新，减少刷新对当前操作的打断；房主可通过成员卡片的“⋯”菜单移出成员或转移房主。

## 修复

- 修复部分设备进入主界面后短暂卡住并退出的问题：本机机库暂不可用时，个人资料中的收藏舰船现在会安全保留，不再触发该崩溃路径。
- 保留机库未读取、部分数据和完整空机库之间的区别，避免把暂时无法确认的舰船误标为“曾拥有”。

## 使用说明

- 本次更新不需要清空账号、个人资料或机库数据。
- 保留信息浮层，本版不提供菜单浮层。
- 当前为公开测试版，遇到问题可通过“帮助与支持”反馈。
