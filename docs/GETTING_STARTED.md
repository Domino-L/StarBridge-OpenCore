# 开始使用 SCM 星海舰桥

## 1. 下载与安装

请下载最新版：

- [官网](https://scstarbridge.com/)：当前版本、更新说明和校验信息；
- [GitHub Releases](https://github.com/Domino-L/StarBridge-OpenCore/releases)：各版本的完整安装包、版本说明和 `SHA256SUMS.txt`。

普通用户请选择名称以 `.exe` 结尾的安装器，GitHub 自动生成的 “Source code” 压缩包只是开放核心源码。安装前先按 [下载帮助](DOWNLOADS.md) 核对大小、SHA-256 和发布者签名。

测试版安装包可能触发 Windows SmartScreen 提示。请确认文件来自官网或 `Domino-L/StarBridge-OpenCore` 的 Releases，再继续安装。

已经装了 0.7.2.1 或更新的版本，可以在客户端“设置”里检查更新，在客户端内升级。0.7.1、0.7.2 请下载完整安装包手动安装：退出客户端后运行，安装到原目录，不用卸载，也不用删除个人数据。

## 2. 登录

打开客户端后，用 SCM 账号登录。第一次使用会有一段简短的使用说明，可以跟着看完，也可以跳过。

未登录时仍可使用部分本地功能，但主舰队、交易大厅、好友、房间和在线同步需要登录。

## 3. 连接游戏日志

进入“设置 › 账号与识别”，在“本机游戏识别”里添加游戏版本（LIVE 正式版、PTU 测试版），可以自动扫描，也可以手动选择这个版本目录下的日志文件：

```text
StarCitizen\LIVE\Game.log
```

选好后启动这个版本并进入游戏，确认 Handle 以后，客户端就会在游戏运行时显示对应的状态。SCM 星海舰桥只在本机读取这份日志，不修改游戏文件，也不向游戏注入代码。

## 4. 主要功能

左侧导航包括：

- **首页**：当前状态和下一步；
- **主舰队**：RSI 官网主舰队的成员、聊天和舰船；
- **交易大厅**：物品和公开挂单；
- **社区组织**：长期的跨舰队组织，可以查找、加入和管理；
- **房间**：临时组队；
- **个人机库**：自己的舰船和共享设置；
- **浮层**：游戏内浮层的信息来源和摆放。游戏在前台时，默认按 Alt+M 打开浮层菜单；
- **工具**：倒计时、计算器，以及按键查看、任务库、蓝图库等参考工具；
- **个人空间**：个人页面、成就中心、好友、消息和通知。

快捷键默认只监听，不拦截按键，游戏和其他程序也会收到。详见 [README](../README.md)。
