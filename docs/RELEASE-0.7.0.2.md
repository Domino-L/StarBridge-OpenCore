# 星海舰桥 0.7.0.2 · 升级衔接与共享设置修复

本次更新改进旧版升级后的衔接，修复桌面图标和共享设置的状态反馈。

## 优化

- 新版正常启动后，自动整理已确认的 0.6.6.1 安装，接替桌面、开始菜单和原有开机启动入口，减少升级后两个版本并存的困扰。
- 清理只处理可确认的旧程序文件和旧安装登记，并保留恢复副本。账号、聊天记录、个人机库和其他本地资料不随旧程序清理；旧程序仍在运行、文件被修改或安装来源无法确认时，会保留旧安装。
- 实时状态共享的正常后台刷新保持静默，不再反复显示“正在应用”。手动应用及确实未能生效的情况仍提供状态反馈。
- 改进安装后的提示：旧版清理尚未确认完成时，提示先保留旧版，避免手动卸载影响新版入口。

## 修复

- 修复桌面快捷方式沿用旧版带底色图标的问题，改用透明图标；保留用户自行指定的图标。
- 修复首次好友共享设置实际已保存、但回执中断后，再次保存仍持续提示未确认的问题。已确认的设置不会重复提交；真实失败或冲突仍保留草稿。

## 使用须知

- 本版保留信息浮层，不提供菜单浮层及其设置、快捷键入口。
- 旧程序恢复副本暂时保留，不会立即回收其占用空间；无需手动删除资料目录。
- 本版本仍为公开测试版。遇到问题请保留草稿，并通过应用内反馈入口提交问题。
